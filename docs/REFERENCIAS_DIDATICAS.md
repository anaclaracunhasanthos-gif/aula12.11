# Referências didáticas consultadas

Repositório consultado somente para leitura: https://github.com/thalesvalente/teaching-mobile. Nenhum arquivo, branch, issue ou configuração desse repositório foi alterado.

## Aula 06 — navegação e formulários

Referência: `lessons/aula-06-navegacao-formularios/PRATICA.md` e `lessons/aula-06-navegacao-formularios/modelo.js`.

Padrões considerados: separar lista, detalhe e formulário; manter identificadores estáveis; validar antes de registrar; controlar o estado do formulário; tratar submissão repetida; oferecer retorno seguro quando não há histórico. O projeto usa navegação por hash compatível com hospedagem estática, em vez de Expo Router, e valida as notas antes do envio.

## Aula 07 — estado, filtros e visualização

Referência: `lessons/aula-07-estado-filtros/apoio/modelo.ts` e `lessons/aula-07-estado-filtros/apoio/PainelAula07.tsx`.

Padrões considerados: funções puras de domínio separadas da interface; filtros sem mutar a coleção de origem; callback de abertura de detalhe; estado controlado; e estados de carregamento, vazio e erro. A busca do Universo IF Avalia amplia a normalização da referência didática para ignorar acentos, conforme requisito do produto.

Os arquivos consultados são referências conceituais. O código deste projeto é uma implementação nova em React Web + Vite + TypeScript, sem copiar ou modificar o aplicativo de ensino.
